# ADR-0010 — Tech Radar

- **Estado:** Superseded
- **Sustituido por:** `docs/architecture/TECH_RADAR.md`

## Motivo

El Tech Radar es un artefacto vivo que cambia conforme evolucionan tecnologías y herramientas. Mantenerlo como ADR convertiría cada actualización operativa en una modificación histórica de una decisión.

El radar vigente se administra en `TECH_RADAR.md`. Este ADR se conserva para trazabilidad.
